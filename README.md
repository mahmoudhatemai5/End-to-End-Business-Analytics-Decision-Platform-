# 🛍️ Olist E-Commerce End-to-End Analytics & ML Platform

> **Digital Egypt Pioneers Initiative (DEPI) - Graduation Project**

## 📌 Project Concept
This project aims to build an end-to-end data science and machine learning platform utilizing the Brazilian E-Commerce public dataset by Olist. The project breaks down the multi-relational database into 5 core business modules to solve real-world operational challenges:

1. **Logistics & Supply Chain:** Analyzing and predicting shipping delivery delays using geospatial features.
2. **Customer Satisfaction:** Performing sentiment analysis and review score prediction to mitigate churn.
3. **Seller Performance:** Applying unsupervised learning (K-Means Clustering) for seller segmentation and quality control.
4. **Financial & Revenue Analytics:** Evaluating payment behaviors, installment trends, and freight-to-price ratios.
5. **MLOps & Dashboard:** Integrating all models into an interactive executive dashboard using Streamlit.

## 👥 Team Structure
Our team consists of 5 members, where each member owns a specific business domain pipeline—from data preprocessing and EDA to machine learning modeling and deployment.
